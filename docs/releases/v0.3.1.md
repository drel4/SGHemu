# SGHemu v0.3.1

## Changes

- Expanded C100XEDA2 and C100XEDD1 support with firmware-matched cellular,
  SMS, tone, WAP and import bindings and shared GPIO/ADC hardware.
- Fixed queued WAP URL text being cleared before use, and corrected the
  gateway's session Resume response. External pages and browser reopening
  were verified with native firmware runs.
- Added charger-completion GPIO/interrupt handling. Reset with the charger
  connected and battery at 100% to see the native egg-hatching screen after
  approximately 20 emulated seconds of active charging. The delay and chip
  identity are provisional firmware-derived fixtures, not measured hardware.
- Added a native emulator-state/speed status bar and SMS message-class selection.
- Added the optional **L&F -> Water (not accurate)** fictional audio fault effect,
  including unstable clocking and voice/sample/PCM corruption. Off by default.

Battery bars retain the firmware's filtering and hysteresis, so percentage
changes are not displayed immediately. Saved WAP profiles are not overwritten:
the built-in gateway needs `10.0.0.1`, Non-secure, port 9201 in the phone settings.

## Compatibility and verification

**C100XEDK1 remains the best-tested firmware.** XEDA2/XEDD1 passed fresh-state
boot, outgoing/incoming calls, SMS, battery ADC and native charge-completion
checks, but Java/media import is not equally verified across versions. Other
Samsung models are not supported yet. This is an experimental pre-release.

The optimized MSVC 2026 x86 Release build and its automated test suite passed.
Startup MA audio matched the preceding dry baseline after a 2-ms alignment.
Windows 7 API/subsystem targeting is retained; execution on Windows 7 is untested.

## Running

Extract the entire archive and launch `build/sghemu-gui.exe`. Keep the directory
layout and open a folder containing both firmware files. Import your own
`M5_EmuHw.dll` for Yamaha audio.

No firmware, Yamaha DLLs, user media, NVM, SIM snapshots or personal settings are
included. Project code/binaries use the WTFPL; third-party notices are preserved.
