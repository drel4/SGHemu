# SGHemu v0.3.2.1

## Fixes

- Added the missing Java DNS/TCP network bridge. Native JAD installation and
  Java HTTP connections no longer rely on the WAP browser's UDP transport.
- Supports nonblocking TCP bind/connect/read/write, asynchronous host DNS,
  native completion callbacks and reset-safe host buffer ownership.
- Enabled separate, disassembly-checked bindings for C100XEDK1, XEDA2 and XEDD1.
- Added Java DNS/connect counters and transferred-byte totals to Diagnostics.

## Internet modes

**Internet** forwards WAP traffic to an external gateway configured in the phone.
**Internet + built-in WAP gateway** supplies the local gateway: **10.0.0.1**,
port **9201**, non-secure. Java TCP/HTTP connects directly in either mode.
This bridges firmware networking services; it does not emulate full GPRS IP
negotiation. Java UDP, listening sockets and TLS offload are not implemented.

## Verification

The full MSVC 2026 x86 Release regression suite passed, including 106 Java
DNS/TCP checks and model-config validation. A native XEDK1 WAP-to-JAD-to-JAR
test downloaded the original 63,614-byte Bobby Carrot game and displayed the
phone's installation-success screen, including a separate asynchronous DNS run.
XEDA2/XEDD1 profiles were boot-tested; their full network installation path is
not yet verified. **C100XEDK1 remains the best-tested firmware.**

The supplied GUI uses Release + PGO. Extract the entire archive and run
**`build/sghemu-gui.exe`**. Supply your own firmware and `M5_EmuHw.dll` for audio.
No firmware, Yamaha DLLs, media, NVM/SIM snapshots, personal settings or PGO
databases are included. Project code/binaries use the WTFPL; third-party notices
remain separate. Windows 7 targeting is retained; execution there is untested.
