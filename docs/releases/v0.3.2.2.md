# SGHemu v0.3.2.2

- LCD zoom (1x, 2x or 3x) now saves immediately and restores on startup.
- Missing or invalid saved zoom values fall back to 2x.
- No changes to CPU, audio or networking emulation.

The GUI is an MSVC 2026 x86 Release + PGO build. Extract the entire archive
and launch **`build/sghemu-gui.exe`**. Supply your own firmware and
`M5_EmuHw.dll` for Yamaha audio. C100XEDK1 remains the best-tested firmware.

No firmware, Yamaha DLLs, media, saved NVM/SIM data, personal settings or PGO
databases are included. Project code/binaries use the WTFPL; third-party
notices remain separate. Windows 7 targeting is retained; execution there is
untested.
